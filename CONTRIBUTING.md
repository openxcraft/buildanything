# Contributing

1. Open an issue describing the change and its affected stage, format, or locale.
2. Make changes from the canonical source or a clearly labeled translation file.
3. Run `bash automation/build.sh` and attach the validation results.
4. Keep generated outputs reproducible and do not commit secrets or personal data.
5. Add or update accessibility notes, attribution, and changelog entries.

Two maintainers review releases. Translation changes need one fluent reviewer and one independent functional reviewer.
