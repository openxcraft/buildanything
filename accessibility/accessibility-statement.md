# Accessibility statement

This package targets WCAG 2.2 AA for HTML and provides plain text, offline, large-print, dyslexia-friendly, RTL-ready, and braille-ready alternatives. The package does not claim that every generated document is conformant solely because an automated checker passes. PDF, EPUB, office files, media, and graphics require format-specific and human review.

Known limitations: Arabic, Spanish, and French locale files are scaffolds until fluent reviewers approve them; braille readiness is limited to plain text and requires a braille-literate reviewer; generated audio is included only when a speech tool is available.
