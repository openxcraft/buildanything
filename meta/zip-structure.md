# ZIP structure and checksums

Every file in this directory is included in the release archive except the archive itself. `MANIFEST.json` records path, size, and SHA-256 for generated package files; `SHA256SUMS.txt` lists the same entries. The checksum files are excluded from their own checksum lists to avoid circular self-reference.

For each path, purpose is self-describing from its name and the package README. Binary outputs are generated by `automation/render_formats.py`; the command and source are recorded in `meta/build-instructions.md`.
