# Governance

The project uses maintainer consensus for routine changes and requires two maintainers for a public release. A decision log records material choices. Contributors may propose forks; forks must preserve attribution and may use distinct branding.

If the lead leaves, the second maintainer rotates credentials, exports the repository, preserves the latest release, updates the canonical notice, and appoints a successor. If no maintainer remains, the latest public release and its open license permit community continuation.
