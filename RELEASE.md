# Release procedure

1. Freeze the canonical source and set `SOURCE_DATE_EPOCH`.
2. Run the validation workflow and review every report.
3. Confirm rights, accessibility, locale status, checksums, mirror parity, and succession records.
4. Tag `v1.0.0` (or the next semantic version), build the ZIP, and publish the release archive.
5. Deposit the release in an independent archive/DOI service when available.
6. Announce through opt-in and community-appropriate channels without mass unsolicited messages.
