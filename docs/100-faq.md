# FAQ

## Is AI required?
No. The workflow has a manual mode and an AI-assisted mode.

## Can an unknown remain unknown?
Not bare. It must become a labeled assumption or an open question with an owner and due date.

## Why is Build last?
Existing ready-made, purchasable, or reusable elements can reduce time and risk. Build only after alternatives fail the specification.

## Does passing G4 mean execution is complete?
No. G4 means the project is ready to execute. Actual execution is outside this workflow.
